# 📖 Project Overview

This project demonstrates an end-to-end Machine Learning workflow for predicting house prices using regression algorithms.

It covers data preparation, visualization, model building, evaluation, optimization, and performance comparison using industry-standard Python libraries.

---

# ✨ Key Features

- 📊 Data Understanding & Preparation
- 📈 Exploratory Data Analysis (EDA)
- 🏠 Simple Linear Regression
- 🏘️ Multiple Linear Regression
- 📉 Polynomial Regression
- ⚙️ Gradient Descent Optimization
- 📏 Model Evaluation using MAE, MSE, RMSE & R²
- ⚖️ Bias–Variance Analysis
- 📋 Final Performance Comparison

# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/dhorajiyamisri/HousePrice_Regression_Project.git
```

Go to the project folder:

```bash
cd HousePrice_Regression_Project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Open the notebooks using Jupyter Notebook or VS Code.
